# YouTube Link Converter

一個 Firefox 擴充功能，提供兩個實用的 YouTube 功能：

## 功能

### 1. 複製乾淨的 YouTube 連結
- 在 YouTube 影片連結上點擊右鍵
- 選擇「複製乾淨的 YouTube 連結」
- 自動去除播放清單、時間戳記等額外參數
- 只保留純粹的影片連結（例如：`https://www.youtube.com/watch?v=VIDEO_ID`）

### 2. 將 Shorts 轉換為普通影片
- 在 YouTube Shorts 頁面點擊擴充功能圖標
- 自動導向到普通的影片播放頁面
- 從 `/shorts/VIDEO_ID` 轉換為 `/watch?v=VIDEO_ID`

## 授權

此專案為個人使用項目。
